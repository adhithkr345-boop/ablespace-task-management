# 🚀 TaskFlow Pro

A modern productivity dashboard built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Undo completed tasks
* Delete tasks
* Search tasks
* Priority selection
* Due dates
* Dark / Light mode
* Theme persistence using localStorage
* Task persistence using localStorage
* Responsive design

## 🛠 Tech Stack

* Next.js 16
* React 19
* TypeScript
* Tailwind CSS

## ▶️ Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## 📦 Production Build

```bash
npm run build
```
